# SOLID

Repositorio de prácticas y ejemplos para aprender y aplicar los principios de diseño SOLID.

## ¿Qué contiene?

Este proyecto reúne ejercicios en varios lenguajes y paradigmas para explorar cada principio con ejemplos concretos:

- Single Responsibility Principle (SRP)
- Open/Closed Principle (OCP)
- Liskov Substitution Principle (LSP)
- Interface Segregation Principle (ISP)
- Dependency Inversion Principle (DIP)

## Estructura

El repositorio está organizado por carpetas temáticas, cada una con ejemplos en distintos lenguajes como:

- C#
- Java
- Python
- TypeScript
- Ruby
- C++


## Temas incluidos

- Herencia y polimorfismo
- Interfaces y abstracciones
- Refactorización de código
- Separación de responsabilidades
- Extensibilidad sin romper el código existente
